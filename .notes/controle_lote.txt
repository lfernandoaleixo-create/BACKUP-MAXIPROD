Tarefas B.I. — Módulo de Controle de Lote

Objetivo
Rastrear cada lote de produção desde a entrada da matéria-prima até a entrega ao cliente.
Controle interno do dashboard — não depende do sistema principal.

Lógica do número de lote
Formato: SKU-DDMMAA-NOTA
Exemplo: EC20-100726-4016
 Parte                           Significado                      Exemplo
 EC20                            SKU do produto finalizado        EC20
 100726                          Data de produção                 10/07/26
                                 (dia/mês/ano)
 4016                            Número da nota fiscal da carga   4016
                                 de madeira

O líder já sabe no início do dia qual carga está usando.

Estrutura no dashboard
2 abas novas no menu:
  Plain Text
  Lançamento | Histórico | Pirografia | Gráficos | Checklist | Mov. Estoque | Lanç



 Aba nova                        Quem usa                         Para quê
 Lançamento de Lote              Líder (tablet)                   Registrar produção do dia com
                                                                  lote
 Lotes                         Gestor / Fiscal                Consultar estoque de lotes e
                                                              histórico

A saída do lote (baixa) NÃO é em aba separada — acontece dentro do pedido, no
momento de enviar para faturamento (onde hoje é o campo de observação).

Fluxo completo
  Plain Text
  ENTRADA
  │ Líder registra produção na aba "Lançamento de Lote"
  │ → Lote criado com saldo
  │
  ESTOQUE
  │ Aba "Lotes" mostra todos os lotes com saldo disponível
  │
  SAÍDA
  │ Líder vai enviar pedido para faturamento (tela do pedido)
  │ → No pedido, campo "Selecionar Lote" (substitui o texto livre de hoje)
  │ → Seleciona lote(s) + quantidade de caixas de cada
  │ → Envia para faturar → saldo do lote baixa automaticamente
  │
  HISTÓRICO
  │ Aba "Lotes" → busca por lote ou por cliente
  │ → Mostra quem recebeu o quê, de qual carga veio




Tela 1 — Aba "Lançamento de Lote" (líder no tablet)
Formulário simples. O líder preenche 3 campos e o sistema gera o lote.
  Plain Text
  ┌──────────────────────────────────────────────────┐
  │ REGISTRAR LOTE                                   │
  ├──────────────────────────────────────────────────┤
  │                                                  │
  │ SKU do produto:      [ dropdown lista de SKUs ] │
  │                                                  │
  │ Nota da carga:       [ campo numérico         ] │
  │                                                  │
  │ Caixas produzidas: [ campo numérico           ] │
  │                                                  │
  │ ─────────────────────────────────────────────── │
  │ Lote gerado: EC20-100726-4016                    │
  │ Data:          10/07/2026 (automática)           │
  │ ─────────────────────────────────────────────── │
  │                                                  │
  │              [ CONFIRMAR ]                         │
  │                                                  │
  └──────────────────────────────────────────────────┘


Regras:
 • Data é automática (dia atual) — líder não digita
 • O sistema monta o código do lote sozinho (SKU + data + nota)
 • Mostra o lote gerado antes de confirmar (para o líder conferir)
 • Após confirmar, saldo aparece na aba "Lotes"


Tela 2 — Seleção de Lote no Pedido (dentro da tela de
envio para faturamento)
Hoje o líder escreve o lote manualmente no campo de observação. Isso muda para um
campo estruturado.
Como é hoje:
  Plain Text
  ┌──────────────────────────────────────────────────┐
  │ CAMPO DE OBSERVAÇÃO                              │
  │ Lote:EC2O-260526-3976                            │
  │ Lote:EC2O-020726-4016                            │
  │ Por Erica em 10/07/2026                          │
  └──────────────────────────────────────────────────┘


Como deve ficar:
  Plain Text
  ┌──────────────────────────────────────────────────────────────────────────┐
  │ LOTES DO PEDIDO                                                          │
  ├──────────────────────────────────────────────────────────────────────────┤
  │                                                                          │
  │ [ + Selecionar Lote ]                                                    │
  │                                                                          │
  │ ┌────────────────────────────────────────────────────────────────────┐ │
  │ │ Lote disponível            │ Saldo │ Caixas neste pedido           │ │
  │ ├────────────────────────────┼────────┼──────────────────────────────┤ │
  │ │ EC20-260526-3976            │ 22 cx │ [ 15 ]                        │ │
  │ │ EC20-020726-4016            │ 48 cx │ [ 30 ]                        │ │
  │ └────────────────────────────┴────────┴──────────────────────────────┘ │
  │                                                                          │
  │ Total de caixas do pedido: 45                                            │
  │                                                                          │
  ├──────────────────────────────────────────────────────────────────────────┤
  │ CAMPO DE OBSERVAÇÃO (texto livre — para outras informações)              │
  │ ________________________________________________________________         │
  │                                                                          │
  └──────────────────────────────────────────────────────────────────────────┘


Regras:
 • Botão "Selecionar Lote" abre lista com lotes que têm saldo > 0
 • Lista filtra automaticamente pelo SKU do pedido (só mostra lotes do produto certo)
 • Líder informa quantas caixas de cada lote vão nesse pedido
 • Não permite colocar mais caixas do que o saldo disponível
 • Pode adicionar múltiplos lotes no mesmo pedido (comum)
 • Ao enviar para faturamento: saldo dos lotes selecionados baixa automaticamente
 • Campo de observação continua existindo para texto livre (outras informações)
 • O lote SAI do campo de observação — agora tem campo próprio
